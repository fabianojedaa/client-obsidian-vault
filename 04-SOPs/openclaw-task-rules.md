# OpenClaw Task Rules

When creating a new task, create a markdown file inside:

02-Tasks/[Machine-Name]/

Each task file must include:

- Task title
- Created date
- Updated date
- Status
- Goal
- Progress
- Agent notes
- Human notes
- Related files
- Final outcome

When updating task progress, update the same task file.

Do not overwrite human notes.

Also add important updates to the daily log.
